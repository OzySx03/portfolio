# ozanemreyildiz.com

Personal site of Ozan Emre Yıldız: MIS student and IT technical support in Istanbul.

Plain HTML, CSS and JavaScript. No build step. Deployed on Vercel.

- `index.html`: content
- `styles.css`: design tokens (light and dark), layout
- `script.js`: theme toggle, header state, scroll reveal

Run locally: open `index.html` in a browser.
